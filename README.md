## 🧩 Engineering Philosophy

> Make it work.
>
> Make it useful.
>
> Make it fast.
>
> Then stare at it for 20 minutes wondering why it works.

I like software that is:

- Simple where it can be
- Powerful where it needs to be
- Observable when it inevitably breaks
- Maintainable by someone who isn't me
